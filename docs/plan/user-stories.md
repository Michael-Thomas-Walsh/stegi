# User stories

Who does what with your app, and why. One line each, always this shape:

> As a **[who]**, I want to **[do what]**, so that **[why it matters]**.

Example (delete it): As a **planner**, I want to **move a slider and see
the density number change**, so that **I can sanity-check a proposal in a
meeting**.
