# User stories

Who does what with your app, and why. One line each, always this shape:

> As a **[who]**, I want to **[do what]**, so that **[why it matters]**.

## Your stories

1. As an **urban planner**, I want to **draw or select a neighbourhood
   boundary and see its rooftops clustered by type**, so that **I can spot
   where rooftop greening would help most, without a GIS specialist**.
2. As an **urban planner**, I want to **rank rooftops by €/°C**, so that
   **I can prioritise a limited greening budget where it cools the most**.
3. As an **architect**, I want to **click a single rooftop and see its
   area, green-type assignment, cooling, and cost**, so that **I can bring
   a defensible number into an early design conversation**.
4. As a **resident**, I want to **toggle a before/after view of my block**,
   so that **I can see what a greened roof would look like and roughly
   what it would cost**.
