# Sketch

**Option A:** photograph your paper sketch and drop the image into `docs/`,
then link it here: `![sketch](./my-sketch.jpg)`

**Option B:** ASCII wireframe, like this:

```
+--------------------------------------+
|  My Project Title                    |

|   +------------------------------+   |

|   |     (the main visual)        |   |
|   |                              |   |
|   +------------------------------+   |
|                                      |
|  Score: 42        [ reset button ]   |
+--------------------------------------+
```

Replace this file's content with your own sketch.
